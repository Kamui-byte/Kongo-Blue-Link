# 🌍 Kongo-Blue-Link

**Plateforme de logistique intelligente pour optimiser la chaîne d'approvisionnement des ports congolais.**

## 🎯 Vision

Connecter efficacement les **Chargeurs** et les **Transporteurs** pour:
- ✅ Fluidifier les échanges commerciaux
- ✅ Réduire les pertes et délais
- ✅ Favoriser le développement économique
- ✅ Optimiser la chaîne logistique

## 🏗️ Architecture

- **Backend:** FastAPI + SQLAlchemy 2 + PostgreSQL
- **Frontend:** React + Vite
- **Auth:** OAuth2 + JWT
- **Cache:** Redis
- **Package Manager:** Poetry

## 📋 Pilliers du Projet

1. **Plateforme de Matching Intelligent** - Connexion Chargeurs ↔ Transporteurs
2. **Optimisation des Tournées** - Suivi en temps réel
3. **Solution Dernier Kilomètre** - Réseau de micro-hubs
